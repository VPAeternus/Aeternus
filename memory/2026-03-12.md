# Session Journal — 2026-03-12

## Learning Loop Closure

- Added a fail-open learning phase to `workflow-run`.
- New module:
  - `tradingagents/dealflow/learning_loop.py`
- New behavior:
  - every completed workflow cycle now attempts:
    - hindsight
    - performance review / signal-family IC persistence
    - signal-family weight writeback
    - source attribution build
    - observed edge reinforcement
  - learning status is recorded in:
    - `eval_results/deal_flow/<date>/learning_status.json`
  - workflow now stays operational if learning fails and marks:
    - `COMPLETED_WITH_LEARNING_DEGRADED`
  - malformed/unsafe writeback is blocked from activation

## Adaptive Weight Writeback

- Added:
  - `tradingagents/dealflow/ic_weight_writeback.py`
- Signal-family IC rows from `signal_family_ic` are now aggregated conservatively into:
  - `eval_results/control/ic_signal_weights.json`
- Rules:
  - minimum recent cycle count required
  - minimum average sample count required
  - bounded additive deltas only
  - no file written if data is insufficient

- `tradingagents/graph/ensemble_weights.py`
  - `update_weights(...)` is no longer a stub
  - it now applies small bounded multiplicative nudges from valid IC input, renormalizes, and records update history

## Source Attribution

- Added:
  - `tradingagents/dealflow/source_attribution.py`
- New artifact:
  - `eval_results/deal_flow/<date>/source_attribution.json`
- Per ticker, it now records:
  - discovery sources
  - collector families present
  - shortlist entry
  - deep-selection flag
  - stage-hit trail

This gives hindsight and future reviews a clean join surface for source/scout edge measurement.

## Observed Edges

- Added:
  - `tradingagents/dealflow/observed_edges.py`
- First slice is intentionally narrow:
  - parse explicit `$TICKER` mentions from manual X-feed catalyst text
  - reinforce AKG `co_mentioned` edges
- This is a high-precision observed-edge builder, not an edge-count maximizer.

## Interactive Manual Workflow

- Added a guided operator mode:
  - `python3 -m cli.main workflow-run --interactive --mode manual --date YYYY-MM-DD`

- Behavior:
  - `workflow-run` stays non-interactive by default
  - `--interactive` is human-only:
    - manual mode only
    - table output only
  - manual stages are now completed inline:
    - X-feed
    - macro
    - earnings/options
  - pasted JSON uses `END` as the multiline terminator

- Operator UX:
  - stage prompts are shown directly in terminal
  - after each manual ingest, CLI prints a short confirmation
  - before automated stages, CLI prints:
    - scouts about to run
    - collectors about to run
  - after each stage, CLI prints a short summary
