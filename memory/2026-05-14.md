- Wording rule from user correction: do not say "missing LLM packets" when counts mix different states. Default wording must be:

- Added `tradingagents/research/fundamental/src/panel/llm_backfill.py`.
- Added CLI command `fundamental-llm-backfill`.
- The tool scans any complete panel CSV across editable inclusive quarters, defaults to `2021Q4` through `2026Q2`, and targets only rows that are LLM-required but not LLM-complete.
- Required flag logic: prefer `llm_required_derived_flag`; fall back to `llm_required_for_full_buy_flag` when needed.
- Complete flag logic: prefer `llm_complete_derived_flag`; fall back to `llm_status == complete` when needed.
- Artifacts written under `eval_results/fundamental/llm_backfill_<start>_<end>` by default:
  - `historical_llm_backfill_missing_required_rows.csv`
  - `historical_llm_backfill_missing_tickers.txt`
  - `historical_llm_backfill_summary.json`
  - `historical_llm_backfill_missing_manifest.jsonl`
- `historical_llm_backfill_evidence_packets.jsonl` is the runnable packet file when source text exists.
- `historical_llm_backfill_evidence_missing.csv` lists required rows where source text could not be found.
- Missing manifest JSONL remains a manifest/packet-prep stub only. It preserves `sample_id`, ticker, quarter, and panel row; it is not final SEC evidence packets.
- Evidence lookup uses direct panel fields first, then conservatively scans `TICKER_*` files under `--sec-text-root` for quarter tokens like `q1x2024`, `q1-2024`, `q12024`, or `2024q1`; generic 10-Q/10-K files are rejected.
- Runnable evidence packets now use a narrow explicit allowlist for identity, pre-LLM score/bucket, tier buckets, and HP/RM pre-LLM/tier-derived extensions only. Theme/narrative/filing-theme conclusions, post-LLM/final/backtest/monitor/decision/candidate-state, price, QoQ, outcome, diagnostic, selection/top15/shadow, forward-return, and source/provenance fields stay out of LLM input. Full rows remain only in the audit manifest.
- Linked `text_path` evidence is guarded like filename fallback evidence: generic 10-Q/10-K paths are rejected and cannot become earnings packets.
- CLI supports `--llm-mode prepare|subagent|in-session|external|post-file` plus model, reasoning, batch, output, `--post-llm`, and `--sec-text-root` controls.
- Non-prepare modes hard-stop if no runnable evidence packets exist.
- `post-file` validates the supplied CSV against generated packet sample IDs, runs strict historical value validation through `validate_llm_result`, and hard-stops when supplied deterministic fields disagree with normalized output; it does not merge historical results yet.
- Historical post-file validation now decodes runner-shaped JSON list fields (`secondary_themes`, `theme_tags`, `theme_evidence`), hard-stops on ticker/quarter mismatch even when `sample_id` matches, and checks deterministic theme acceleration fields.
