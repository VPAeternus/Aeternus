- Corrected the Grok-tab selection rule after user clarified the intended operator behavior:
  - desired behavior:
    - use the current front Grok tab if one is already open
    - otherwise open a new Grok tab in the current front Chrome window
    - never reuse an arbitrary background Grok tab from some other window/session
  - root cause:
    - `open_fresh_chat()` was still scanning all Chrome windows/tabs and reusing the first `grok.com` tab it found
  - fix:
    - `open_fresh_chat()` now checks only `URL of active tab of front window`
    - if that tab is already `https://grok.com...`, it reuses it
    - otherwise it opens a new Grok tab in `front window`
    - background-tab scanning logic was removed entirely
