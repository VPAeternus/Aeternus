# Venture Mode mechanical triggers

Use only filing-grounded evidence. No discretionary score assignment.

## Venture Score
`Venture Score = Wave Exposure + Asymmetric Upside + Fundable Scaling + Filing Delta + Wave Torque / Operating Leverage + Incumbent Saturation Penalty + False-Promise Penalty`

## A. Wave Exposure (`0-5`)
Start at `0`. Add `+1` for each trigger present in the active filing.
1. Explicit `AI`, `AI/ML`, `artificial intelligence`, or `data center` demand linkage.
2. Company product is described as serving a wave-enabling layer: power, storage, optical interconnect, networking, or infrastructure.
3. Filing says demand / revenue / shipments / deployments increased because of AI, cloud, datacenter, or enterprise SSD demand.
4. Filing ties products to specific deployment contexts such as datacenters, enterprise SSD, AI infrastructure, public clouds, or grid/interconnection bypass.
5. Wave linkage appears in more than one place or as both business description and operating update.

## B. Asymmetric Upside (`0-5`)
Start at `0`.
1. `+2` if the company is not the already-dominant incumbent in the comparison set.
2. `+1` if the filing describes a large growth surface or category expansion path from current products.
3. `+1` if the filing does **not** describe the company as an `industry leader based on revenue and market share` or equivalent obvious leadership language.
4. `+1` if upside depends on a still-developing wave rather than continuation of already-known scale.

## C. Fundable Scaling (`0-5`)
Start at `0`. Add `+1` for each trigger present.
1. Strong liquidity / cash / financing access is explicitly stated.
2. Strategic financing, partner, utility, policy, or deployment scaffold is explicitly stated.
3. Filing shows manufacturing, supply, or commercial capacity sufficient to participate in demand.
4. Filing shows improved pricing / margin / profitability / capital efficiency versus prior stressed period.
5. Filing shows multi-year runway, durable demand expectation, or persistent supply-demand tightness.

## D. Filing Delta (`0-5`)
Score only versus the company’s prior filing.
1. `+1` if the active filing adds a clearer wave framing than the prior filing.
2. `+1` if it adds stronger demand / shipment / revenue / deployment evidence.
3. `+1` if it adds stronger scaling / financing / liquidity support.
4. `+1` if it adds stronger margin / pricing / utilization / operating leverage evidence.
5. `+1` if the filing is a clear breakaway step-change versus the prior filing.

## E. Wave Torque / Operating Leverage (`0-3`)
Start at `0`. Add `+1` for each trigger present.
1. Filing shows the company is already in a bottleneck supplier / enabling layer.
2. Filing shows AI / datacenter / cloud demand is already lifting shipments, revenue, exabytes, or similar operating metrics.
3. Filing shows pricing, margin, utilization, or mix leverage from the wave.

## F. Incumbent Saturation Penalty (`0` to `-5`)
Start at `0`.
1. `-3` if company is the already-obvious incumbent leader in the comparison set.
2. `-1` if the filing mainly confirms continuation rather than new hidden upside.
3. `-1` if the filing uses explicit leadership / dominance language suggesting upside is already well known.

## G. False-Promise Penalty (`0` to `-5`)
Start at `0`. Subtract `1` for each trigger present.
1. Heavy financing dependence or need for external funding.
2. Bookings delays / deployment delays / order uncertainty.
3. Margin pressure / underutilization / inventory overhang / commoditization.
4. Policy / export / China / tariff / regulatory fragility.
5. Customer concentration / cancellation / backlog uncertainty.

## Venture tie-break
If totals tie, prefer:
1. higher `Wave Exposure`
2. then higher `Wave Torque / Operating Leverage`
3. then higher `Asymmetric Upside`
4. then higher `Filing Delta`
5. then lower saturation penalty
