## Implementation

### `generate_dashboard(track_record_path, output_path, spy_benchmark)` → str

Pure Python rendering (f-strings). Chart.js from CDN. Self-contained HTML.

**Dashboard sections:**
- Header: "Aeternus Track Record" + date range + total analyses
- Summary row: Win rate, Avg return, Cumulative alpha vs SPY, Sharpe ratio (if enough data)
- Table: All rated tickers — score, decision, entry price, current/exit price, return %, days held, status (OPEN/CLOSED)
- Chart: Cumulative return line vs SPY (Chart.js CDN — no build step)
- Footer: "Generated by Aeternus Score engine. Not investment advice."

**Use the existing dark-mode HTML template style from `content_posts.py` lines 451-520 as reference** for CSS theming (same dark/light responsive design).

**Data source:** Load from `eval_results/track_record.json` (array of rating dicts). Each dict has: ticker, rating, score/aeternus_score, price_at_rating, close_price (if closed), close_date, status, confidence.

**Stats computation:**
- Win rate: % of closed trades where return matches direction (buy→positive, sell→negative)
- Avg return: mean return across closed trades
- Sharpe: (mean_return - risk_free) / std_return (annualized, assume 252 trading days)
- Alpha vs SPY: cumulative return minus SPY return over same period

**SPY benchmark:** Use yfinance to fetch SPY price at first rating date and current price. If yfinance fails, skip benchmark.

### CLI Command

```
aeternus track-record-dashboard --output docs/track_record.html
aeternus track-record-dashboard --output docs/track_record.html --open
```

The `--open` flag calls `webbrowser.open()` on the output path.
