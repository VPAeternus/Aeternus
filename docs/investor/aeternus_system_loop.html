The Learning Loop
▶

Every outcome strengthens the next decision. The system feeds results back into Stage 1, closing the loop.

1. Credibility Ledger

Bayesian Beta(2,2) prior tracks accuracy of 5 agents + 5 pillars. Scores are injected into the risk debate — agents that have been wrong get discounted automatically.

2. Investment Committee

Weekly automated review reads calibration data and writes signal weight adjustments, confidence re-calibration, and sector overrides. Each directive expires after 7 days.

3. Hebbian Node Learning

Win → node weight +5%. Loss → node weight −8% (asymmetric, range 0.5–2.0×). Winners rise in universe ranking; losers fade. Graph learns which nodes produce alpha.

4. Calibration Engine

Predicted win rate vs actual win rate per confidence bucket. Detects systematic over- or under-confidence and corrects future conviction levels.

5. Factor Fingerprinting

Every closed trade carries its entry pillar breakdown and weight regime. Enables factor-level quality analysis: which pillars actually predicted returns?

6. Edge Strengthening

Supply chain edges gain +0.05 × confidence per re-confirmation. Centrality calculations strengthen well-corroborated relationships, making the graph smarter over time.

Outcomes → Credibility + Hebbian + Calibration → Stronger Universe Discovery The loop closes. Every trade makes the system better.
