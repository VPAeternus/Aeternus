Scoring Engine

Five pillars. One composite score.

Fundamental30%
P/E ratio, operating margins, Piotroski F-Score, EV/EBITDA. 90-day AKG fundamentals cache — one API call per quarter per ticker.
Coherence25%
Cross-pillar signal alignment score. Contradiction penalty applied when fundamental, sentiment, and macro signals conflict. Meta-analysis reduces conviction on diverging tracks.
